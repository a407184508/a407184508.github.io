## 为什么写这个博客

这个站点同时承担两件事：

1. 一个可以长期归档的**公开博客**；
2. 一个只在本地运行的**创作工作区**。

写作、排版、发布都在同一个地方完成，不再需要在多个工具之间复制粘贴。

## 工作方式

- 内容以 Markdown 保存，预览与发布使用同一套渲染链。
- 草稿只存在浏览器本地，只有点击发布才会进入仓库。
- 发布由 GitHub Actions 构建，几分钟后线上生效。

> 发布是复制，不是同步：本地修改要再次发布才会更新线上。

## 代码示例

```ts
export function greet(name: string): string {
  return `你好，${name}`
}
```
