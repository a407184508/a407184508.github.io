## 1. 背景与目标

### 1.1 问题

- **创作分发重复**：同一篇内容要分别处理公众号排版、小红书配图、博客发布，重复劳动且样式不稳定。
- **信息越积越乱**：浏览器标签、书签、历史记录没有统一归口，收藏后找不到。
- **生活记录分散**：健康、运动、孩子成长、家庭规划散落在多个应用，无法合并回顾。
- **工具绑定与隐私顾虑**：云端工具限制导出、加水印，健康和家庭数据不适合上传。

### 1.2 产品回应

做一个部署在 GitHub Pages 上的**本地优先个人站点**，四个模块共用同一套数据与发布通道：

- 创作工具负责“写一次、多平台用”；
- 博客负责公开发布与长期归档；
- 工作台负责私密记录与回顾；
- 网页整理负责把浏览器信息归集为可检索的资源库。

私密数据只存在本机浏览器；只有用户主动发布的文章与导航页进入公开站点。

### 1.3 可观察结果

- 同一份 Markdown 可以完成：发布博客、复制到公众号、导出长图。
- 浏览器中保存的工作集可以一键恢复，收藏内容可以在 30 秒内被搜到。
- 工作台记录可在时间线回看，并能生成月度回顾。
- 私密数据不会出现在公开站点。
- 更换电脑或清空浏览器前，可以通过备份包完整迁移。

### 1.4 产品契约

| 项 | 定义 |
|---|---|
| 主用户 | 本人，单人使用 |
| 使用设备 | 桌面浏览器为主；手机仅保证浏览样式 |
| 触发 | 写文章、做封面、整理浏览器、记录生活 |
| 核心任务 | 创作与分发；信息归集；生活记录与回顾 |
| 完成证据 | 文章在公开站点可见；公众号富文本与图片可直接粘贴或保存；资源可被搜索到；回顾可导出 |
| 失败恢复 | 草稿自动保留；发布可重试；可导出 Markdown 手动发布；数据可备份恢复 |
| 信任条件 | 私密数据不公开；发布前可预览；所有数据可导出 |

## 2. 定位与约束

### 2.1 产品定位

- **单人产品**：不做账号、注册、登录、权限体系。
- **本地优先**：私密数据存在浏览器本地，不经过服务器。
- **静态发布**：博客是静态站点，由 GitHub Actions 构建，托管在 GitHub Pages（默认 `github.io` 域名）。
- **配置即文件**：站点信息、导航、标签与扩展配置以 JSON 文件存放在仓库，直接修改 JSON 即可生效，不依赖后台管理界面。
- **可迁移**：所有数据可导出；不锁定在某个平台。
- **桌面优先**：手机只做阅读适配，不承诺完整编辑与记录体验。

### 2.2 平台约束及影响

| 约束 | 产品影响 |
|---|---|
| 单用户、无账号 | 无登录与权限管理；数据按浏览器隔离，换浏览器看不到同一份数据 |
| 无服务器 | 无云同步、无后台定时任务、无服务端图片处理；“定时”改为打开应用时检查或手动触发 |
| 静态托管 GitHub Pages（`github.io`） | 博客只能是静态页面；发布依赖构建，不能即时生效；默认使用 GitHub 提供的域名 |
| GitHub Actions 构建 | 发布是异步任务；需要状态展示、失败重试与手动兜底 |
| GitHub 作为发布通道 | 需要用户提供 Token；Token 只存本地，可随时撤销 |
| 外部服务仅限 GitHub | 不接入其他云服务、AI、图床或第三方 API；工具与配置只能来自本地或 GitHub |
| 浏览器本地存储 | 容量有限；清除站点数据会丢失；必须提供备份与恢复 |
| 桌面为主 | 手机只保证阅读与简单浏览，不作为主要记录入口 |
| Chrome/Edge 扩展 | 其他浏览器扩展后置 `[Assumption]` |

### 2.3 公开与私密边界

| 数据 | 默认 | 可否公开 | 说明 |
|---|---|---|---|
| 已发布文章 | 公开 | 是 | 进入博客仓库并参与构建 |
| 草稿 | 私密 | 否 | 只存本地，除非主动发布 |
| 工作台全部数据 | 私密 | 仅回顾草稿 | 不能直接公开，必须人工脱敏后经博客发布 |
| 资源库 | 私密 | 仅选中的导航页 | 默认不公开 |
| 主题、模板、画布工程 | 私密 | 可导出分享 | 不自动公开 |
| 站点配置 JSON | 公开 | 是 | 与博客源码一起存放在仓库，修改后重新构建生效 |
| GitHub Token | 私密 | 否 | 仅本地保存，可撤销 |

**发布是复制，不是同步**：本地修改不会自动更新线上文章；需要再次发布才会生效。下线文章后，本地文章回到草稿状态，发布历史保留在 Git 中。

## 4. 产品模型

### 4.1 角色与权限

| 角色 | 能做什么 | 不能做什么 |
|---|---|---|
| 本人（本机浏览器） | 读写本地全部数据；发布与下线文章；管理 GitHub 连接 | 不能在其他设备看到同一份本地数据 |
| 公开访客 | 浏览已发布文章、标签、归档、RSS、公开导航页 | 不能访问草稿、工作台、资源库 |
| GitHub | 接收文章提交、执行构建、托管站点 | 不参与产品内权限，不作为产品角色 |

产品内没有登录态。GitHub 连接只用于发布，不改变本地数据的私密性。

### 4.2 核心对象

| 对象 | 说明 | 可见性 |
|---|---|---|
| Article 文章 | 含草稿与已发布版本，带标题、slug、标签、摘要、正文 | 草稿私密；已发布公开 |
| PublishJob 发布任务 | 一次发布从提交到构建的结果记录 | 私密 |
| Theme 主题 | 公众号排版、长图、首图共用的样式配置 | 私密，可导出 |
| Template 模板 | 首图与内容图的预设布局 | 私密，可导出 |
| CanvasProject 画布工程 | 首图/内容图的多页工程 | 私密 |
| Resource 资源 | 标签页、书签、手动添加的网页 | 私密 |
| Collection 集合 | 工作集、主题分组、导航页分组 | 私密；选中项可公开 |
| Tag 标签 | 资源的分类标签 | 私密 |
| Snapshot 快照 | 某次保存或某天的工作集记录 | 私密 |
| Person 人物 | 本人、孩子、家庭成员 | 私密 |
| Entry 条目 | 时间线上的记录，含类型、日期、内容、附件 | 私密 |
| Metric 指标 | 体重、睡眠、血压、身高体重等数值记录 | 私密 |
| Goal 目标 | 个人、孩子、家庭的目标与进度 | 私密 |
| Review 回顾 | 周/月/年回顾，含自动统计与回答 | 私密；可生成博客草稿 |
| FamilyPlan 家庭规划 | 旅行、教育、居住、轻量财务目标 | 私密 |
| Backup 备份 | 一次完整导出产生的数据包 | 私密 |

### 4.3 状态与转换

**文章（Article）**

| 状态 | 进入条件 | 可执行操作 | 退出 |
|---|---|---|---|
| 草稿 | 新建、发布失败、下线后 | 编辑、预览、发布、删除 | → 发布中 |
| 发布中 | 已提交发布任务 | 查看进度、刷新状态 | → 已发布 / 发布失败 |
| 已发布 | 提交成功且构建成功 | 查看、编辑、重新发布、下线 | → 发布中 / 草稿 |
| 发布失败 | 提交失败或构建失败 | 查看原因、重试、导出 Markdown、继续编辑 | → 发布中 / 草稿 |

已发布文章编辑后状态保持“已发布”，但标记“有未发布修改”；公开页面仍显示上次发布版本，重新发布成功后清除标记。

**资源（Resource）**

| 状态 | 进入条件 | 可执行操作 | 退出 |
|---|---|---|---|
| 待整理 | 新采集或导入 | 打标签、分组、归档、删除 | → 正常 / 已归档 |
| 正常 | 整理完成 | 搜索、编辑备注、归档、标记失效 | → 已归档 / 已失效 |
| 已失效 | 连续两次检测失败或手动标记 | 恢复、删除、保留备注 | → 正常 |
| 已归档 | 用户主动归档 | 恢复、删除 | → 正常 |

**发布任务（PublishJob）**

| 状态 | 进入条件 | 可见反馈 | 退出 |
|---|---|---|---|
| 提交中 | 开始上传图片与文章 | 进度与当前步骤 | → 构建中 / 失败 |
| 构建中 | 提交成功，等待 Actions | 最后检查时间、手动刷新 | → 成功 / 失败 |
| 成功 | 构建完成 | 文章链接 | 终态 |
| 失败 | 提交或构建失败 | 失败阶段、原因、恢复动作 | 重试生成新任务 |

## 5. 功能需求

### 5.1 基础能力（P0）

#### 5.1.1 入口与导航

- 顶部导航固定展示：文章、工具箱、设置；P1 起增加工作台、资源库。
- 当前阶段未启用的模块不显示空入口，避免出现无法使用的页面。
- 默认首页：P0 为文章列表；P1 起为概览页，展示最近文章、待写回顾、最近记录。
- 页面刷新后保持当前页面；浏览器前进/后退可用。
- 桌面优先；窄屏下导航折叠，内容单列展示。

#### 5.1.2 本地数据与自动保存

- 所有私密数据保存在当前浏览器本地，不因浏览行为自动上传。
- 编辑类页面在停止输入 2 秒或最长 5 秒后自动保存；离开页面前强制保存一次。
- 保存状态可见：保存中、已保存、保存失败。
- 保存失败时保留编辑内容并提示原因；存储空间不足时阻断继续保存，引导导出或清理。
- 异常关闭后重新打开，若存在未正常保存的内容，提示恢复最近一次自动保存。
- 无痕模式可用但不保证持久化，首次进入时提示“关闭窗口后数据可能丢失”。

#### 5.1.3 备份、导出与恢复

- **完整备份**：导出包含全部数据与图片附件的备份包；导入后可恢复文章、草稿、工作台、资源库、主题与设置。
- **分模块导出**：文章导出 Markdown（含 frontmatter），工作台导出 JSON/CSV，资源库导出 JSON/Markdown。
- 导入前展示预览：将新增、更新、跳过的数量列出，由用户确认后执行。
- 冲突按稳定 ID 与更新时间判断；更新时间较新者覆盖较旧者；资源按归一化 URL 去重，文章按 slug 去重。
- 导入文件损坏或版本高于当前应用支持范围时，整包拒绝，不做部分导入，并说明原因。
- 每 30 天提醒一次备份；执行清空数据、批量删除等高风险操作前，先提示导出备份。
- 备份包不包含 GitHub Token；恢复后需重新连接。

#### 5.1.4 设置

- 外观：浅色、深色、跟随系统。
- 编辑器：字号、行高、自动保存开关。
- 数据：备份、导入、导出、清空本地数据。
- GitHub：仓库、分支、Token、连接状态、断开连接。
- 外部服务：仅 GitHub 连接；不提供其他云端能力入口。
- 扩展：连接状态与数据交换说明（P1）。
- 清空本地数据需二次确认，并再次提示导出备份。

#### 5.1.5 反馈与错误处理

- 所有操作有即时反馈：成功提示、失败原因、下一步动作。
- 空状态说明“为什么为空”和“可以做什么”，不使用空白页。
- 长任务展示进度；可安全取消的操作提供取消，不可取消的操作明确说明。
- 错误日志仅保存在本地，可导出用于排查；不接入第三方统计或上报。

### 5.2 内容创作工具箱（B）

#### 5.2.1 B1 公众号 Markdown 排版（P0）

**用途**：把 Markdown 转成可直接粘贴到公众号编辑器的富文本，减少重复排版。

**布局**

- 左侧 Markdown 编辑区，右侧实时预览区。
- 顶部：主题选择、链接处理、复制、导出 HTML。
- 底部：字数、保存状态、复制结果提示。

**触发与流程**

1. 新建、导入 `.md`，或从博客草稿载入内容。
2. 编辑 Markdown，选择主题，预览效果。
3. 处理图片与链接。
4. 点击复制，粘贴到公众号编辑器；或导出 HTML 文件兜底。

**字段**

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 标题 | 否 | 空 | 仅用于本地草稿命名，不进入正文 |
| 正文 | 是 | 空 | Markdown |
| 主题 | 是 | 默认主题 | 影响预览与复制结果 |
| 链接处理 | 是 | 转文末引用 | 公众号不支持外链时的处理方式 |
| 代码块处理 | 是 | 内联样式 | 可选“转为图片” |
| 图片 | 否 | 跟随正文 | 本地图片，复制时尽量一并携带 |

**处理规则**

- 支持 CommonMark 与 GFM 常用语法：标题、段落、加粗、斜体、删除线、列表、引用、分割线、图片、表格、代码块、链接、脚注。
- 原始 HTML 先清理，不在白名单内的标签移除并提示；不执行脚本。
- 主题内置 5–8 套，支持调整主色、字号、行高、间距、圆角；预览与复制必须使用同一套样式。
- 复制结果为内联样式 HTML，不依赖外部 CSS；公众号会过滤的样式不写入。
- 外链默认转为文末编号引用；用户可改为“保留纯文本 URL”。正文中的链接不直接可点，避免粘贴后失效。
- 图片随富文本复制；若粘贴后图片缺失，提供“下载全部图片”和逐张插入提示。
- 代码块使用内联样式；可切换为图片，避免公众号过滤等宽字体或背景色。
- 宽表格提示可能超出屏幕；提供转图片选项 `[Assumption]`。
- 草稿自动保存；复制或导出不改变草稿状态。

**异常**

| 情况 | 用户看到 | 处理 |
|---|---|---|
| 正文为空 | 复制按钮禁用 | 提示先输入内容 |
| 图片读取失败 | 失败图片列表 | 重试、移除、替换 |
| 剪贴板权限被拒 | 提示无法写入剪贴板 | 导出 HTML 兜底 |
| 粘贴后样式丢失 | 提示可能被目标编辑器过滤 | 切换“兼容模式”，减少复杂样式 |
| 文档过大 | 复制前警告 | 建议拆分或导出 HTML |
| 主题配置无效 | 回退默认主题 | 提示具体错误 |

#### 5.2.2 B2 Markdown 转长图（P0）

**用途**：把 Markdown 转成可直接发布的连续长图或分页图片，复用到小红书、朋友圈、公众号配图。

**字段**

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| 来源 Markdown | 是 | 当前编辑内容 | 可与 B1 共用 |
| 主题 | 是 | 默认主题 | 与 B1 共用主题系统 |
| 页面尺寸 | 是 | 1080×1440 | 另提供 1080×1920、900×1200 |
| 导出方式 | 是 | 分页图片 | 单张长图 / 分页图片 |
| 清晰度 | 是 | 2x | 1x / 2x |
| 页脚 | 否 | 页码 | 可加署名，可关闭 |
| 分页断点 | 否 | 自动 | 支持手动插入分页标记 |

**处理规则**

- 先完整渲染，再按块高度切分；优先在段落、标题、列表、引用之间断开。
- 标题不得单独留在页尾，必须与后续至少一个内容块同页。
- 代码块、表格、图片默认不跨页；单块高于一页时，代码块允许带“续”标记拆分，表格提示拆成多表，图片等比缩小。
- 支持手动分页标记，手动断点优先于自动断点。
- 单张长图超出浏览器可导出高度时，强制改为分页并说明原因。
- 导出文件命名：`日期-标题-页码-尺寸.png`。
- 长图导出失败时按页重试，列出失败页，不静默丢弃。

**异常**

| 情况 | 处理 |
|---|---|
| 正文为空 | 禁用导出 |
| 字体缺失 | 使用回退字体并提示 |
| 图片加载失败 | 占位并列出失败图片，允许重试 |
| 外链图片跨域 | 提示先将图片保存到本地再导出 |
| 导出超时 | 分页逐张重试，展示进度 |
| 单页内容过高 | 强制分页或提示手动断点 |

#### 5.2.3 B3 小红书首图画布（P1）

**用途**：用画布和模板快速制作小红书首图，并导出可直接发布的图片。

**画布与页面**

- 尺寸预设：3:4（1080×1440）、1:1（1080×1080）、4:3（1080×810）、9:16（1080×1920）。
- 一个工程支持多页，最多 9 页；可复制页、排序、批量导出。
- 画布最大 2160×3840；超出时提示并限制 `[Assumption]`。

**元素**

| 元素 | 能力 |
|---|---|
| 背景 | 纯色、渐变、图片、纹理 |
| 文字 | 字体、字号、字重、颜色、行高、字距、对齐、描边、阴影、底色高亮 |
| 图片 | 上传、裁剪、圆角、透明度、基础蒙版 |
| 形状 | 矩形、圆形、线条、箭头、标签块 |
| 贴纸 | 内置少量常用贴纸与图标 |
| 二维码 | P2 提供，可放置署名或链接 |

**编辑辅助**

- 网格、对齐吸附、等距分布、图层排序、锁定、显示/隐藏。
- 撤销/重做、复制/粘贴、键盘微调。
- 画布缩放与适配窗口；导出尺寸不受缩放影响。

**模板**

- 内置标题式、对比式、清单式、人物封面式模板。
- 一键切换配色与字体；换模板不丢失已填文字与图片。
- 模板只提供布局与样式，不包含具体文案。

**导出与工程**

- 导出当前页或全部页；PNG/JPG；1x/2x；PNG 支持透明背景。
- 工程自动保存，可再次打开编辑；支持复制工程。
- 导出前检查未加载图片与缺失字体，明确提示后再继续。

**异常**

| 情况 | 处理 |
|---|---|
| 字体缺失 | 回退字体并提示；导出前再次确认 |
| 图片加载失败 | 显示占位，禁止静默导出 |
| 存储空间不足 | 阻断保存，提示导出工程或清理 |
| 画布超限 | 限制尺寸并提示 |
| 导出空白 | 等待资源加载后重试，仍失败则提示具体元素 |

**字体规则**

- 仅内置可商用字体。
- 用户导入字体为 P2；导入时提示版权责任由用户承担。

#### 5.2.4 B4 内容图与配图（P2）

- 预设类型：引用卡、金句卡、数据卡、代码卡、文章封面。
- 统一复用 B3 画布引擎与导出能力。
- 每种预设提供必填字段与默认布局；导出规则与 B3 一致。
- 文章封面可直接关联博客文章，发布时作为封面图使用。

#### 5.2.5 B5 主题与模板库（P1）

- 主题与模板统一管理，支持收藏、设为默认、重命名、删除。
- 支持导入/导出 JSON，文件包含名称、版本、样式配置。
- 导入无效或版本不兼容时拒绝，并说明原因，不覆盖现有主题。
- 模板更新不影响已经创建的工程；工程保留创建时的样式快照。
- 内置与自定义主题分开标识，内置主题不可删除。

### 5.3 博客站点（D）

#### 5.3.1 公开站点页面

| 页面 | 内容 | 规则 |
|---|---|---|
| 首页 | 最新文章、站点简介、标签入口 | 只展示已发布文章 |
| 文章详情 | 标题、日期、标签、正文、目录、上一篇/下一篇 | 正文由 Markdown 渲染；代码高亮；图片自适应 |
| 标签页 | 标签列表与对应文章 | 标签去重、去首尾空格 |
| 归档页 | 按年月分组 | 按发布日期倒序 |
| 搜索页 | 标题、摘要、标签、正文搜索（P1） | 无结果时给出清除筛选建议 |
| 关于页 | 站点与作者介绍 | 内容可编辑 |
| 导航页 | 资源库选中的公开集合（P1） | 只展示显式选中的内容 |
| 404 页 | 返回首页入口 | 静态生成 |
| RSS | 最新文章订阅 | 默认最新 20 篇 `[Assumption]` |

- 响应式布局；P1 支持深色模式。
- 不做评论、点赞、关注、分享统计。
- 基础 SEO：标题、描述、站点地图、语义化标题层级；P1 增加社交分享卡片信息。

#### 5.3.2 文章编写

**字段**

| 字段 | 必填 | 默认 | 规则 |
|---|---|---|---|
| 标题 | 是 | 空 | 不超过 120 字 |
| Slug | 是 | 由标题生成 | 仅小写字母、数字、连字符；全局唯一；可编辑 |
| 摘要 | 否 | 正文前 120 字 | 用于列表与搜索 |
| 标签 | 否 | 空 | 可多选、可新建 |
| 封面 | 否 | 空 | 本地图片；发布时一并提交 |
| 发布日期 | 是 | 当前时间 | 不允许未来日期，避免误解为定时发布 |
| 正文 | 是 | 空 | Markdown |
| 状态 | 系统维护 | 草稿 | 见 4.3 |

**规则**

- Slug 默认由标题生成；中文标题无法生成时使用 `post-日期-序号` `[Assumption]`。用户可手动修改。
- 本地已存在相同 slug 时提示冲突；发布前还需检查远端是否已存在同名文章。
- 预览使用与公开站点相同的渲染规则，避免“预览正常、发布错位”。
- 编辑已发布文章不会立即改变公开页面；保存后标记“有未发布修改”，重新发布成功后清除标记。
- 草稿自动保存；支持复制文章、删除草稿、导入/导出 Markdown。
- 删除草稿需二次确认；已发布文章必须先下线才能删除。
- 发布失败的文章保留草稿内容与失败原因，不丢失编辑结果。

#### 5.3.3 发布流程

**前置条件**

- 已完成 GitHub 连接：仓库、分支、Token 有效且有写入权限。
- 文章通过校验：标题、slug、正文非空；slug 不冲突。
- 网络可用；离线时发布按钮禁用并说明原因。

**流程**

1. 点击发布，展示公开预览与隐私提醒。
2. 校验字段与远端冲突。
3. 上传文章图片；任一图片失败则中止，不提交文章，避免线上正文出现坏图。
4. 提交 Markdown 与图片，创建发布任务。
5. 等待构建；页面展示“提交中/构建中”和最后检查时间。
6. 构建成功后文章状态变为已发布，展示公开链接。

**规则**

- 同一篇文章重新发布时覆盖同一路径，Git 历史保留旧版本。
- 发布任务可重试；重试不会生成重复文章文件。
- 发布只提交已发布内容，草稿不进入仓库。
- 发布前检查敏感信息：手机号、住址、孩子学校等仅做提醒，不自动阻断。
- 下线需二次确认；下线后从站点移除并触发重新构建，本地文章回到草稿。
- 下线不是删除：Git 历史仍可找回；产品内提供“重新发布”。

#### 5.3.4 发布状态与失败恢复

| 失败阶段 | 用户看到 | 恢复动作 |
|---|---|---|
| 未连接 GitHub | 发布按钮不可用，说明缺少连接 | 前往设置连接 |
| Token 无效或过期 | 明确提示重新授权 | 更新 Token 后重试 |
| 权限不足 | 提示仓库或分支无写入权限 | 检查仓库权限后重试 |
| 网络失败 | 提交未完成，草稿保留 | 重试；或导出 Markdown 手动提交 |
| 远端 slug 冲突 | 显示冲突文章路径 | 覆盖确认，或修改 slug 后发布 |
| 图片上传失败 | 列出失败图片 | 重试、移除图片、导出兜底 |
| 构建失败 | 显示失败阶段与日志入口 | 修复后重试；导出 Markdown 兜底 |
| 构建超时 | 状态保持构建中，显示最后检查时间 | 手动刷新；必要时重试 |

- 不自动循环重试；每次重试由用户触发。
- 构建结果无法实时推送，只能在页面打开或手动刷新时更新。
- 发布失败不清空本地草稿，也不回滚已提交的远端内容；P1 提供发布历史与回滚入口。

#### 5.3.5 GitHub 连接

- 连接字段：仓库所有者、仓库名、分支、Token。
- 连接时校验：仓库存在、分支存在、Token 有内容写入权限。
- 首次使用需一次性初始化仓库：仓库中包含站点代码、构建配置，并已开启 GitHub Pages。应用检测不到构建配置时不阻止连接，但发布前提示先完成初始化；P1 提供初始化指引。
- 默认使用 GitHub Pages 提供的 `github.io` 域名，不配置自定义域名；博客仓库需为公开仓库。
- 只保留一个连接；更换连接需先断开。
- Token 仅保存在本地，保存后不再完整显示；断开连接立即清除。
- Token 只发送给 GitHub，不发送到其他地址。
- 连接失效时，文章保持草稿，发布按钮提示重新连接。

#### 5.3.6 图片与静态资源

- 发布时把本地图片一并提交到仓库，文章引用稳定路径。
- 图片提交前压缩，避免过大文件拖慢构建 `[Assumption]`。
- 公开仓库中的图片可被公开访问；首次发布时提示这一点。
- 允许使用外部图片链接，但提示可能失效或被防盗链拦截。
- 未使用的图片不自动删除，避免破坏历史文章；清理能力放 P2。

#### 5.3.7 跨模块入口

- B1 可把当前 Markdown“发送到博客草稿”，生成一篇草稿。
- C8 回顾可生成博客草稿，但必须先经过脱敏检查。
- A 的导航页可生成/更新一篇静态页面（P1）。
- B2、B3 的产物是图片，不直接作为文章发布；可插入文章正文。

#### 5.3.8 JSON 配置与扩展

**用途**：把站点信息、导航、标签体系与可选扩展从代码中分离，允许直接修改仓库中的 JSON 文件完成配置。

**配置文件**

- 仓库内提供独立配置目录，至少包含：站点信息、导航、标签、扩展入口四类 JSON。
- 配置文件随博客源码公开；不得写入 Token、健康数据、家庭信息等私密内容。
- 构建时读取配置；修改并提交后由 Actions 重新构建生效，不需要改代码。
- 配置结构带版本号，便于后续扩展与兼容处理。

**标签配置**

- 文章 frontmatter 中声明的标签仍会自动汇总。
- 标签 JSON 可补充显示名称、排序、颜色、描述与分组；未在 JSON 中声明的标签按默认样式展示，不丢失。
- 删除标签配置不会删除文章；文章仍保留原标签文本。

**扩展配置**

- JSON 可注册额外导航项与页面入口，用于后续增加工具或内容分区，不需要改站点框架。
- 扩展项必须指向已存在的页面或文章；目标不存在时构建给出警告，并在站点隐藏该入口，不出现死链。
- 扩展配置只描述“有哪些入口”，不执行脚本、不加载外部服务。

**校验与异常**

| 情况 | 处理 |
|---|---|
| JSON 语法错误 | 构建失败，指出文件与位置；线上保持上一版本 |
| 必填字段缺失 | 该配置项跳过并警告，不影响其他页面 |
| 未知字段 | 忽略并警告，保证向后兼容 |
| 重复标签或导航 | 合并或提示重复，保留第一个 |
| 扩展目标不存在 | 隐藏入口并警告，不生成死链 |
| 配置文件过大或嵌套过深 | 构建拒绝并提示简化 |

- P0 只支持直接编辑文件；P1 可在应用内查看配置说明与校验结果，但仍以仓库文件为准。
- 本地预览读取同一套 JSON，避免预览与线上不一致。
- 配置变更属于公开内容变更，提交前需自行确认不含敏感信息。

### 5.4 个人成长工作台（C）

#### 5.4.1 快速记录（P1）

- 全局入口：页面右下角“快速记录”，任意页面可唤起。
- 第一步选类型：运动、健康、孩子、学习（学习 P2）。
- 第二步只填必要字段，保存后立即回到原页面。
- 日期默认当天，可改为过去日期；不允许未来日期。
- 单条记录目标在 30 秒内完成；不做强制打卡、不要求连续记录。
- 保存成功提示“已记录”，并提供“再记一条”和“查看时间线”。
- 手机浏览器只保证可查看；记录体验以桌面为准。

#### 5.4.2 C1 人生阶段与里程碑（P1）

- 人生阶段：标题、开始日期、结束日期（可为空）、阶段总结、标签。
- 阶段允许重叠，按开始时间排序；同一时间最多标记一个“当前阶段”。
- 里程碑：标题、日期、人物、描述、照片、标签。
- 时间轴：按年/月切换，可按模块与人物筛选。
- “那年今日”：展示往年同一天及同月的记录。
- 编辑、删除需确认；删除人物时需选择保留记录或一并删除。
- 空状态提示从“添加第一个里程碑”开始。

#### 5.4.3 C3 健康指标（P1）

**P1 指标**

| 指标 | 单位 | 录入规则 |
|---|---|---|
| 体重 | kg | 正数，保留 1 位小数 |
| 睡眠 | 小时 | 0–24，保留 1 位小数 |
| 血压 | mmHg | 收缩压/舒张压成对录入 |

- 其他指标（体脂、心率、身高）P2 扩展。
- 同一天同一指标允许多条记录；趋势图取当天最后一条，列表展示全部。
- 趋势视图：近 7 天、30 天、90 天、全部。
- 用户可设置个人参考范围；超出范围仅高亮提示，不提供医疗建议。
- 体检报告以附件归档：日期、类型、备注、文件；附件只存本地。
- 单位固定，P1 不做单位换算。

#### 5.4.4 C4 运动（P1）

**字段**

| 字段 | 必填 | 说明 |
|---|---|---|
| 类型 | 是 | 跑步、力量、游泳、球类、骑行、其他 |
| 日期 | 是 | 默认当天，不可未来 |
| 时长 | 是 | 分钟，正数 |
| 距离 | 否 | 公里，仅对有距离的运动展示 |
| 强度 | 否 | 1–5 |
| 感受 | 否 | 简短文字 |
| 备注 | 否 | 自由文本 |

- 同一天允许多条记录（如早晚各一次）。
- 周目标支持“每周次数”或“每周分钟数”，二选一。
- 统计：本周/本月次数、总时长、总距离、热力图。
- 连续记录按本地日期计算，断一天即中断，不做补签。
- 编辑、删除需确认；删除后统计立即更新。

#### 5.4.5 C6 孩子成长（P1）

- 支持多个孩子；每个孩子独立档案。
- 基础信息：昵称、生日、性别（可选）、头像。
- 身高体重：复用指标记录，展示成长曲线；与本人指标分开统计。
- 疫苗：疫苗名称、日期、剂次、备注；只做记录，不生成接种计划或医疗建议。
- 里程碑：标题、日期、类别（运动/语言/社交/教育/其他）、描述、照片。
- 语录：内容、日期、场景；支持按时间浏览。
- 教育：当前阶段、学校（私密）、兴趣班、备注。
- 年龄展示：未满 2 岁按月龄；满 2 岁按“X 岁 Y 个月”。
- 孩子数据默认私密，不提供直接公开开关；只能经回顾草稿人工脱敏后发布。
- 删除孩子档案时，必须选择“保留记录并解除关联”或“连同记录一起删除”。

#### 5.4.6 C8 回顾（P1）

- P1 支持月度回顾；P2 增加周回顾与年度回顾。
- 每个回顾包含 3 个默认问题：本月最有成就感的事、最想改进的事、下阶段重点；问题可编辑。
- 自动汇总：记录条数、运动次数与时长、健康指标变化、孩子新里程碑、本月标签分布。
- 自动汇总只读取数据，不替用户下结论；用户可修改文字。
- 回顾可保存草稿、完成、再次编辑。
- 导出 Markdown 或长图（复用 B2）。
- 发布到博客时只生成草稿，必须经过脱敏预览：隐藏姓名、学校、具体健康数值等；用户确认“已检查敏感信息”后才可发布。
- 无服务端提醒：打开应用时，若上一周期已结束且未写回顾，展示“待回顾”提示，可关闭。

#### 5.4.7 C2 学习（P2）

- 读书：书名、作者、状态（想读/在读/读完）、评分、笔记、摘录。
- 课程与技能：名称、状态、学习时长、阶段目标。
- 笔记可“发送到博客草稿”，形成输入到输出的链路。
- 统计：年度阅读本数、学习天数。

#### 5.4.8 C5 饮食（P2）

- 记录三餐照片或文字、在家/外食、饮水杯数。
- 不做卡路里计算与营养分析。
- 周视图回顾“这周吃了什么”，支持按天展开。
- 照片只存本地；占用空间过大时提示清理。

#### 5.4.9 C7 家庭规划（P2）

- 家庭目标：类别（旅行/教育/居住/健康/其他）、周期、目标、进度。
- 家庭事件：纪念日、生日、家庭活动，可设置每年重复。
- 旅行：目的地、日期、同行人、行程备注、照片；预算为可选的粗略金额。
- 轻量财务只记录目标与进度，不做记账、账户、流水。

#### 5.4.10 工作台隐私

- 全部数据默认私密，不进入公开站点。
- 不支持单条记录直接生成公开链接。
- 公开路径只有一条：生成回顾草稿 → 人工脱敏 → 经博客发布。
- 导出时明确提示文件包含敏感信息，由用户自行保管。

### 5.5 网页聚合与标签整理（A）

#### 5.5.1 采集（P1）

- 扩展入口：点击图标或快捷键，选择采集范围：当前窗口、所有窗口、选中标签。
- 采集内容：标题、URL、favicon、域名、采集时间、来源。
- URL 归一化：去除常见跟踪参数、锚点、尾部斜杠；默认规则可关闭。
- 重复链接不新增，更新“最近出现时间”，保留首次收藏时间。
- 采集结果先进入“待整理”，展示新增数、重复数，可撤销本次采集。
- 支持手动添加链接；支持导入浏览器书签 HTML。
- 历史记录默认不采集；开启时需选择时间范围并提示隐私影响。
- 扩展无权限时，说明缺少哪项权限以及如何授权。
- 扩展数据只存本地，不经过服务器。

#### 5.5.2 整理与标签（P1）

- 自动分组：先按域名分组，再按主题规则聚合；分组结果可合并、拆分、重命名。
- 标签建议：只使用本地规则（域名、关键词、路径）；不调用云端模型。规则建议需用户确认后才写入。
- 标签支持层级、别名、颜色、合并；合并后旧标签不再出现。
- 批量操作：打标签、移动分组、归档、删除。
- 自动整理不删除任何资源；每次整理可撤销。
- 资源备注字段“为什么收藏”，用于日后检索。
- 同一 URL 出现不同标题时，保留最近标题，不覆盖用户备注。

#### 5.5.3 工作集（P1）

- 把当前窗口或所有标签保存为工作集：名称、备注、颜色。
- 恢复工作集：打开全部链接；已打开的页面跳过；展示打开、跳过、失败数量。
- 每次保存生成快照；扩展启动时若当天无快照，生成一次每日快照。
- 删除工作集不关闭浏览器标签，只删除记录。
- 工作集可导出为 Markdown 链接列表。
- 部分链接打开失败时列出失败项，支持重试或复制链接。

#### 5.5.4 搜索（P1）

- 搜索范围：标题、URL、域名、标签、备注、摘要。
- 过滤：域名、标签、来源、时间范围、状态（正常/失效/归档）。
- 排序：相关度、最近访问、收藏时间。
- 设计目标：5000 条资源下搜索响应小于 500ms。
- 无结果时提示清除筛选或调整关键词，不展示空白列表。

#### 5.5.5 导航页（P1）

- 从资源库选择集合或单条资源，生成公开导航页。
- 可调整分组顺序、图标、备注；支持预览。
- 只有显式选中的内容会公开；未选中的资源绝不出现。
- 导航页通过博客发布流程生成静态页面；修改后需重新发布。
- 下线导航页只影响公开页面，不影响本地资源库。
- 发布前提示：链接、标题与备注将公开。

#### 5.5.6 周报（P2）

- 手动生成本周/本月报告：访问最多的站点、新增资源、清理数量、标签分布。
- 生成 Markdown 或长图；可选择发布到博客。
- 无服务端定时：周期结束后在打开应用时提示“可生成周报”，由用户触发。
- 不提供 AI 摘要；周报只用本地统计生成。

#### 5.5.7 失效链接检测（P2）

- 手动扫描或打开应用时提示扫描；不做后台定时。
- 连续两次检测失败才标记“已失效”；单次超时不标记。
- 检测过程展示进度，可取消；支持重试。
- 失效资源保留标题、备注与标签，供用户决定删除或恢复。
- 检测频率受限，避免对目标站点造成压力；具体间隔 `[TBD]`。

#### 5.5.8 扩展盘点（P2）

- 列出已安装扩展：名称、版本、启用状态、用户备注。
- 展示权限概览，帮助识别高权限扩展 `[Assumption]`。
- 只提供记录与提醒，不自动停用或卸载扩展。
- “扩展”若实际指更多内容类型而非浏览器插件，本项需重新定义 `[TBD]`。

#### 5.5.9 扩展与主站的数据交换

- 扩展是采集端，主站是整理端。
- P1：扩展导出资源包，主站导入；导入前按 URL 去重并预览。
- P2：主站页面打开时，扩展可将新增资源推送到主站；仍为本地传输，不经过服务器。
- 不提供后台自动同步；两边数据不一致时以导入预览结果为准。

#### 5.5.10 资源库隐私

- 不保存网页全文，只保存元信息、备注与可选摘要。
- 历史记录采集默认关闭。
- 不接入第三方 AI 或云服务；资源数据只在本机与扩展之间流转。
- 公开范围仅限导航页中显式选中的集合。

## 6. 共享规则与异常

### 6.1 时间与日期

- 全部按用户本地时区计算；“今天”以本地 00:00 为界。
- 仅有日期的记录不存时间；有时间的记录（文章、发布任务）存完整时间。
- 不允许未来日期用于记录与文章发布，避免与“定时发布”混淆。

### 6.2 标识、去重与冲突

| 对象 | 去重依据 | 冲突处理 |
|---|---|---|
| 资源 | 归一化 URL | 保留首次收藏时间，更新最近出现时间 |
| 文章 | slug | 本地冲突阻止保存；远端冲突要求覆盖或改 slug |
| 标签 | 名称（忽略首尾空格） | 合并到已有标签 |
| 工作台记录 | 稳定 ID | 导入时按更新时间较新者覆盖 |
| 人物 | 稳定 ID | 导入时按更新时间较新者覆盖 |

导入冲突必须先预览再执行，不静默覆盖。

### 6.3 自动保存与崩溃恢复

- 编辑停止 2 秒或最长 5 秒自动保存；离开页面前强制保存。
- 保存失败保留编辑内容，展示原因；存储空间不足时阻断继续写入。
- 异常关闭后重新打开，提供“恢复最近自动保存”入口。
- 自动保存不替代备份；备份仍需用户主动导出。

### 6.4 删除规则

- 删除均为永久删除，需二次确认；P2 再考虑回收站。
- 已发布文章必须先下线，才能删除本地文章。
- 删除工作集不关闭浏览器标签。
- 删除人物必须选择“保留记录并解除关联”或“连同记录一起删除”。
- 删除主题/模板不影响已创建的工程；工程保留样式快照。

### 6.5 图片与附件

- 图片与附件只存本地；完整备份包包含这些文件。
- 发布博客时，正文图片随文章提交到仓库；公开仓库意味着图片可被公开访问。
- 公众号排版不依赖图床：图片随复制携带，失败时提示手动上传。
- 外部图片链接可能失效；导出与发布前提示风险。
- 图片压缩在导出或发布时进行，原图保留本地。

### 6.6 隐私与发布

- 默认私密，公开必须由用户显式触发。
- 所有发布前提供预览，并提示将公开的内容范围。
- 工作台数据只能通过回顾草稿间接公开，必须人工脱敏并确认。
- 不接入云端 AI 或第三方服务；所有处理在本地完成。
- GitHub Token 仅本地保存，仅发送给 GitHub。

### 6.7 无服务端任务

- 不存在后台定时任务、推送通知与自动同步。
- 外部依赖仅 GitHub（提交、构建、配置读取）；不调用其他云服务或第三方接口。
- 周报、失效检测、回顾提醒等“定时”能力，实际在打开应用或扩展时检查，或由用户手动触发。
- 发布状态无法实时推送，只能在页面打开或手动刷新时更新。

### 6.8 容量与性能目标

| 场景 | 目标 |
|---|---|
| 资源搜索 | 5000 条数据下小于 500ms |
| 时间线 | 5000 条记录滚动流畅 |
| 长图导出 | 3000 字文章 1 分钟内完成 |
| 首图导出 | 1080×1440 @2x 清晰无锯齿 |
| 自动保存 | 编辑过程中无明显卡顿 |

以上为设计目标；触及浏览器存储上限时，优先保证数据不丢并引导导出。

### 6.9 设备与浏览器边界

- 桌面 Chrome/Edge 为完整功能环境；Safari 等浏览器后置。
- 手机只保证公开站点阅读与基础浏览，不承诺完整编辑、画布、工作台记录。
- 不支持跨设备同步；每个浏览器环境的数据独立。
- 无痕模式数据不持久；清理站点数据会导致本地数据丢失，需提前备份。

### 6.10 版本与回滚

- 已发布文章每次发布在 Git 中保留历史版本；P0 不提供产品内回滚。
- 已发布文章编辑后标记“有未发布修改”，公开页面保持上次发布版本；重新发布后更新。
- P1 提供发布历史查看与“重新发布旧版本”。
- P2 提供一键回滚到上一版本。
- 本地主题与模板导入时保留版本号；不兼容版本拒绝导入。

## 7. 已确认决策、待确认问题与假设

### 7.1 已确认决策

| 编号 | 决策 | 对产品的影响 |
|---|---|---|
| D1 | 博客直接托管在 GitHub Pages，使用 Actions 自动构建，默认 `github.io` 域名，仓库公开 | 不配置自定义域名；发布即提交并构建；文章源码与图片公开 |
| D2 | 站点信息、导航、标签与扩展通过仓库内 JSON 配置，直接修改 JSON 即可 | 不依赖后台配置界面；配置变更走提交与构建；配置必须公开且不含敏感信息 |
| D3 | 只使用本地能力与 GitHub；不接入云端服务器、AI、图床或第三方 API | 所有处理在本地完成；发布、构建、配置读取是唯一外部依赖 |

### 7.2 待确认

| 编号 | 问题 | 影响 | 当前处理 |
|---|---|---|---|
| Q1 | 公众号复制携带图片失败时，是否需要增加“GitHub 仓库外链”兜底？ | 影响 B1 体验；不引入第三方图床 | 先按复制携带 + 手动上传；失败率高再评估 GitHub 外链 |
| Q2 | “扩展盘点”中的“扩展”是否指浏览器插件？ | 若指更多内容类型，需要重新定义该功能 | 暂按浏览器插件理解，P2 确认 |
| Q3 | JSON 配置需要覆盖到什么粒度：仅站点/标签/导航，还是也包括工具模块开关？ | 影响配置结构与构建复杂度 | P0 先覆盖站点、导航、标签、扩展入口 |

### 7.3 已按假设处理

| 假设 | 处理方式 |
|---|---|
| 单用户、无账号 | 不设计登录、权限、多人协作 |
| 手机只浏览 | 不做移动端记录与同步 |
| 桌面 Chrome/Edge | 扩展与完整功能优先支持 Chrome/Edge |
| 博客公开、工作台私密 | 公开与私密边界按 2.3 执行 |
| 无服务器 | 不做云同步、后台任务、实时推送 |
| 一键发布依赖 GitHub Token | Token 仅本地保存，可撤销 |
| 只内置可商用字体 | 用户导入字体放 P2，并提示版权责任 |
| 不做评论与统计 | 公开站点保持静态、轻量 |
| 不接入云端 AI | 标签、周报、回顾均只用本地规则与统计 |
