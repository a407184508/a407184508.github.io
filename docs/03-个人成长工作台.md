# 模块 C：个人成长工作台

> 优先级：P1（与工具箱并行，越早开始积累数据越好）  
> 关联：[产品总览](./00-产品总览.md)

## 1. 目标

用**轻量记录 + 定期回顾**，把人生阶段、学习、健康、运动、饮食、孩子成长、家庭规划串成一条可回看的时间线。

关键不是"打卡"，而是**三个月后还能翻出来看，并能自动生成回顾**。

## 2. 设计原则

1. **记录 ≤ 30 秒**：默认字段最少，能一句话就不填表单。
2. **先时间线，后统计**：先保证"记得下来"，再谈图表。
3. **先回顾，后打卡**：以周/月回顾驱动记录，而不是靠意志力每日打卡。
4. **模块可开关**：不想记饮食就关掉，不制造负担。
5. **敏感数据本地优先**：健康、家庭、孩子信息默认不公开。
6. **一切可导出**：Markdown / CSV / JSON，随时可离开。

## 3. 功能模块

### C1 人生阶段与里程碑（P0）

- 自定义人生阶段：求学、职业、成家、育儿等，含起止时间、关键词、阶段总结。
- 里程碑：事件、日期、地点、照片、感受、标签。
- 时间轴视图：按年/月缩放，支持按模块与人物筛选。
- "那年今日"：回顾往年同一天。
- 阶段目标：每个阶段设定 1–3 个目标与完成度。

### C2 学习成长（P1）

- 读书：书名、作者、状态（想读/在读/读完）、评分、笔记、摘录。
- 课程与技能：技能树、学习时长、阶段目标。
- 笔记可关联到博客草稿，形成"输入 → 输出"链路。
- 统计：年度阅读本数、学习天数、连续记录。

### C3 健康（P1）

- 指标记录：体重、体脂、睡眠时长、血压、心率（按需启用）。
- 趋势图与简单阈值提醒（非医疗建议）。
- 体检报告附件归档（PDF/图片），按日期索引。
- 用药/就诊记录（可选，P2）。

### C4 运动（P1）

- 记录类型：跑步、力量、游泳、球类、骑行、其他。
- 字段：日期、时长、距离、强度、感受、备注。
- 周/月统计：次数、总时长、总距离、热力图。
- 目标：每周次数/每月里程，显示完成度。
- 连续记录天数（streak）。

### C5 饮食（P2）

- 轻记录：三餐照片或文字、外食/自煮、饮水杯数。
- 不做卡路里精细计算（除非确认需要）。
- 周视图回顾"这周吃了什么"。

### C6 孩子成长（P1）

- 基础信息：生日、性别、身高体重曲线。
- 健康：疫苗记录、体检记录、就诊记录。
- 里程碑：第一次说话、走路、上学、换牙等，含日期、照片、描述。
- 语录与作品：一句话、画作、手工作品照片。
- 教育：当前阶段、兴趣班、阶段规划。
- 时间轴与"成长对比"（同月龄照片/身高对比）。

### C7 家庭规划（P1）

- 年度家庭目标：旅行、储蓄、居住、教育、健康。
- 家庭事件日历：纪念日、生日、家庭活动。
- 旅行计划与回忆：目的地、行程、花费（粗粒度）、照片。
- 轻量财务目标：只记目标与进度，不做记账系统。

### C8 回顾与报告（P0）

- 模板化回顾：日/周/月/年，各 3 个问题即可（如"本月最有成就感的事？""最想改进的？"）。
- 自动汇总：记录条数、运动次数、阅读本数、孩子新里程碑、健康变化。
- 生成 Markdown / 长图，可选择发布到博客。
- 年度总结自动草稿：按模块汇总，支持脱敏（隐藏具体数值/姓名）。
- 回顾提醒：周日/月末，可关闭。

## 4. 数据模型（初稿）

```
Person
  id, name, birthday, relation(self/child/family), avatar

LifeStage
  id, title, startDate, endDate, summary, tags[]

Entry
  id, type(study/health/sport/diet/milestone/family/child)
  personId, date, title, content
  metrics(json), tags[], attachments[]
  visibility(private/blog)

Goal
  id, scope(personal/family/child), period(year/month/week)
  title, target, progress, status

Review
  id, periodType(day/week/month/year), periodStart
  answers(json), summary, createdAt

Metric
  id, personId, kind(weight/sleep/height/...), value, unit, recordedAt

FamilyPlan
  id, category(travel/finance/education/housing)
  title, period, budget, status, note
```

## 5. 关键交互

- **全局快速记录**：任意页面唤起 → 选类型（运动/健康/孩子/学习）→ 一句话或几个字段 → 保存（≤ 30 秒）。
- **首页仪表盘**：本周概览、连续记录、待写回顾、孩子最近里程碑、家庭近期事件。
- **时间线**：默认全部，可按模块/人物筛选；支持年/月缩放。
- **图表**：体重趋势、运动热力图、阅读统计、孩子身高曲线。
- **移动端优先的记录页**：适合手机单手操作，支持拍照上传。
- **回顾向导**：引导式 3 问，自动带上本月数据。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 隐私 | 默认仅本地/自托管；公开到博客需逐条显式勾选并脱敏 |
| 安全 | 每日自动备份，保留 30 天；支持加密导出 |
| 性能 | 5000 条记录时间线流畅；图表渲染 < 1s |
| 可用性 | 断网可用；移动端浏览器可正常记录 |
| 可迁移 | 全量导出 JSON/CSV；支持导入恢复 |

## 7. 本期不做

- 不做社交、家庭多账号协作（除非确认伴侣共同记录）。
- 不做医疗诊断或健康建议。
- 不做完整记账/财务系统。
- 不做卡路里数据库与营养分析。
- 不做硬件数据自动同步（Apple Health/手环）——可列为后续。

## 8. MVP 范围与验收标准

**MVP 范围**：C1 时间轴与里程碑 + C4 运动 + C3 基础指标（体重/睡眠）+ C6 孩子里程碑 + C8 月度回顾。

**验收标准**

- [ ] 30 秒内完成一条记录（含移动端）。
- [ ] 月度回顾一键生成，统计数字与明细一致。
- [ ] 时间线可按模块/人物筛选，5000 条数据滚动流畅。
- [ ] 一键导出全部数据，且可重新导入。
- [ ] 私密记录不会出现在任何公开页面。

## 9. 待确认

1. 是否需要伴侣/家人共同记录？若需要，是否接受多用户与权限设计？
2. 饮食记录要做到什么粒度：照片级、文字级，还是卡路里级？
3. 是否接入 Apple Health / 智能手环自动同步？
4. 是否需要提醒（疫苗、体检、纪念日、回顾）？渠道是站内、邮件还是飞书/微信？
5. 孩子信息记录到几岁、哪些维度？是否需要导出成"成长册"？
6. 回顾内容发布到博客时，脱敏规则如何定义（姓名、学校、具体数值）？
7. 数据是纯本地，还是需要服务端 + 多设备同步？
